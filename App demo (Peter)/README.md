# DocDrop · App Demo (Peter)

Patientendokumente fotografieren, prüfen und strukturiert in die Akte übernehmen.

**Öffnen:** `DocDrop.html` herunterladen und im Browser öffnen. Läuft komplett lokal, ohne Server.

**Ausprobieren:** Eines der synthetischen Beispiele laden (Laborbefund, Entlassbrief, ähnlicher Name, gemischter Stapel), dann Auswerten, Patient bestätigen, Abschnitte prüfen.

Nur synthetische Daten. Keine echten Patientendokumente verwenden.
